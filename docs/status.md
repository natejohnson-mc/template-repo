# Project status

This starter has no project implementation or operational state to report.
Use the [README adoption steps](../README.md#use-this-template) to initialize a
new project, then replace this paragraph with its actual status.

Maintain one entry per item in the relevant section below; move it as its state
changes rather than duplicating it. Link to findings and evidence in an owning
record or pull request. Remove or condense resolved entries; this page is not a
completed-task log. Follow the
[documentation policy](../AGENTS.md#documentation-workflow) before creating a
separate record.

## Active work

No project work is recorded. For ongoing work, include the item, progress,
owning record or pull request, and next action. Note related verification in
that entry rather than repeating it in another section.

## Pending verification

No project verification is recorded. Use this section for verification gaps
without an active-work entry. Distinguish implementation, merge, deployment,
and verification. Link to the expected result and how it will be checked, and
name the next action.

## Opportunities

No project improvement topics are recorded. When planning future work or working
on a listed topic, search related records, Git history, and pull requests first.
For each candidate or deferred item, include the problem or desired outcome,
disposition, evidence or plan link, and next planning action. Update it when
work produces a material finding, plan, deferral, or completion; move it to
Active work when implementation begins.
