# Run repository tools

No manually invoked project tools are included in this starter.
Use [development](docs/development.md) for setup and repository checks.

## Add a tool entry

When a tool becomes available, document its purpose, prerequisites, working
directory, exact command, required inputs, and expected result. Explain whether
the command reads or changes state and how to verify success.

Link to the owning component record or
[runbook](docs/runbooks/README.md) for configuration, recovery, and operational
details. Keep implementation in versioned source rather than reproducing it
here. Publish commands only when their entry points exist.
