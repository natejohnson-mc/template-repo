Use this file when planning future work or investigating an existing topic.
For each topic, record the problem or desired outcome, its disposition, a link
to existing evidence or plans, and the next planning action. Search related
records and pull requests before proposing a new plan.

Update an entry when work produces a material finding, plan, deferral, or
completion. Link to implementation and verification details in the owning
record or pull request. Apply the
[documentation rules](AGENTS.md#documentation-workflow) before creating a record.
